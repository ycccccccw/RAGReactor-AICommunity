## 冷启动与故障回退

无行为的新账号返回：

```text
personalized=false fallback=cold_start
```

将社区索引路径故意设置为不存在文件后，两次结果完全一致，并返回：

```text
personalized=false fallback=community_index_unavailable
```

证明 AI/索引异常不会导致 Feed 失败，仍会依据热门、质量、新鲜度和稳定探索返回内容。

## 当前边界

- 候选池当前最多读取 500 条帖子，适合现阶段数据规模；达到更大规模后应把四路召回拆成
  独立 Top-K 查询。
- 探索分由用户名和帖子 ID 的稳定哈希生成，分页期间不会因为纯随机数造成剧烈抖动。
- `for_you` 使用偏移游标。如果候选统计在两次分页请求之间发生大幅变化，理论上仍可能发生
  排名位移；后续大规模版本可增加短期推荐快照缓存。
- 图片无文字的帖子暂时没有语义向量，但仍可通过热门、最新、质量和探索通道获得曝光。
